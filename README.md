# Photo Studio

Photo Studio 是运行于飞牛桌面的开源图像编辑器，适合照片修饰、图片合成和日常设计。图像处理主要在浏览器中完成，无需另装桌面编辑软件。

- **照片调整**：裁剪、旋转、自由变换，以及亮度、色阶、曲线与色彩调整。
- **图层合成**：图层分组、混合模式、透明度、蒙版与剪贴蒙版。
- **绘画与设计**：画笔、橡皮擦、渐变、仿制与修复工具，以及文字、形状和路径。
- **文件与导出**：支持 PSD、PSB、PNG、JPEG、WebP、TIFF 等格式；使用 `.photo` 项目继续编辑，或导出为常用图片格式与 PSD。
- **中英文界面**：默认简体中文，在“编辑 → 首选项 → 界面 → 界面语言”即时切换，不重建当前编辑器。

应用版本 **1.0.0**。上游开发者 [HeyPuter](https://github.com/HeyPuter)，飞牛版发布者 **6uos**，源码：[songdone/PhotoStudio](https://github.com/songdone/PhotoStudio)。

## 使用 NAS 文件

从飞牛文件管理器的“打开方式”，或应用内“从 NAS 打开…”选择文件。NAS 条目可从“最近使用”重新打开，每次仍检查当前账号权限。

- **另存为 → NAS 文件夹**：选择格式、文件名和目标文件夹，按飞牛提示授权。
- **导出为 → 保存到 NAS**：保存副本，不改变当前文档的保存目标。
- **保存**：NAS 来源文档在原格式下尝试写回原路径。已有文件使用版本校验；冲突必须确认，确认后再次变化会停止覆盖。
- **下载到本机 / Puter**：是独立的保存目的地，不会在 NAS 保存失败时静默替代它。

NAS 保存同时依赖当前账号的写授权、应用用户的文件系统权限及目标文件夹的权限设置。不能保留原文件所有者、组、权限或 ACL 时，应用拒绝覆盖，可尝试用新文件名另存为；文件夹权限无法安全继承时也会拒绝。应用不会自动扩大权限。取消或失败保留未保存的文档；结果不确定时，请保持文档打开并先检查 NAS 文件。

复杂 PSD 的部分效果可能转为像素或以合成预览打开，建议保留原文件。大尺寸、多图层文件的体验取决于当前设备与浏览器性能。

本地图片编辑与导出无需 Puter 账户。云存储、AI 和协作是可选的 Puter 服务，需要联网及相应账户，条款与额度以服务方为准。

## 构建

需要 Node.js 22.12+、Go 1.25+、Python 3 和本机官方 [fnpack](https://developer.fnnas.com/docs/cli/fnpack/)。前端依赖按锁文件安装，Go 依赖使用仓库中的 vendor 源码。

```sh
npm --prefix web ci --ignore-scripts --no-audit --no-fund
sh scripts/build.sh --build-id <新的唯一构建编号> --nosign
```

默认构建前端和 `linux/amd64`、`linux/arm64` 两架构安装包。输出及验包记录位于 `开发存档/<构建编号>/`；`dist/` 是构建工具指向最近一次成功打包目录的兼容入口。`--nosign` 生成未签名本地候选，不代表已通过应用中心审核。

日常前端开发：

```sh
npm --prefix web run dev -- --host 127.0.0.1
```

文件选择、目录授权、写入和用户隔离需在目标 fnOS 版本上验证；浏览器模拟与本机测试不能替代设备兼容性验证。

## 权限与运行方式

原生 Go 服务由专用 `photostudio` 应用用户运行，通过 fnOS Unix Socket 网关提供界面和受限 NAS 文件接口，不提供终端、Docker 或管理员权限。

- 当前账号身份由飞牛网关注入，前端不能自行声明身份。
- `trim.file.userAccess` 用于请求官方文件授权，`trim.file.userAcl` 检查当前账号读写权限；声明 scope 不等于已经获得授权。
- 本地开发 TCP 接口不能通过伪造身份读取或写入 NAS 文件。
- NAS 接口只接受受限的 `/volN/...` 支持格式路径，拒绝目录作为文件、隐藏路径、路径穿越与符号链接；单文件上限 512 MiB。
- HTTP 环境使用 WebGL2；HTTPS 且浏览器支持时可用 WebGPU。依赖浏览器安全上下文的功能需要 HTTPS。
